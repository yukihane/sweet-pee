# プロジェクト概要

## プロジェクト名

血糖値データ統合アプリ（仮称：GlucoseSync）

## 目的

糖尿病患者の血糖値測定データをGoogleヘルスコネクトに統合し、一元的な健康データ管理を実現する。

## 背景

- ユーザーが糖尿病と診断され、血糖値の測定・記録が必要
- 測定機器は既存のAndroidアプリ経由でe-SMBGに連携している
- しかし、既存アプリにはGoogleヘルスコネクトへの送信機能がない
- e-SMBGでは血糖値データと詳細な時刻情報が利用可能
- Android端末で完結する解決策が必要

## 核心的な要求

1. **データ取得**: e-SMBGから血糖値データ（時刻情報含む）を取得
2. **データ変換**: mg/dL → mmol/L への単位変換
3. **データ統合**: Googleヘルスコネクトへの自動送信
4. **Android完結**: 端末内で全処理を完結

## 制約条件

- 医療機器の直接通信プロトコルは非公開
- 他アプリのデータ直接読み取りは不可能
- e-SMBGの利用規約遵守が必要
- 個人医療情報の適切な取り扱いが必須

## 成功指標

- 血糖値データの自動同期が動作する
- データの正確性が保たれる（単位変換含む）
- 安定した動作（エラー処理の充実）
- ユーザビリティの確保
